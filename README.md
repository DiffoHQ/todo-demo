# todo

A todo list for the terminal, with natural-language due dates and recurring todos.

    todo add "renew passport" friday
    todo add "call mum" tomorrow
    todo add "water plants" every 3 days
    todo add "standup" every monday until 2026-12-31
    todo list
    todo done 3        # a repeating todo rolls to its next date
    todo skip 4        # skip one occurrence

Recurring todos are covered in [docs/recurrence.md](docs/recurrence.md).
